# 家纺布料图案结构化生成

这个 Skill 只在用户通过输入框的 `/` 选择 `home-textile-pattern` 后生效。未选择时，不要主动套用本流程，也不要把本文件内容当作系统提示词预载。

## 对话规则

- 一次只问一个问题，等用户回答后再进入下一步。
- 每次给出 2–5 个清晰、可点击的编号选项，并保留 `0. 自定义描述`。
- 用户可以回复编号、选项文字或自由描述；自由描述优先于默认值。
- 需要等待用户确认时，发送一个 `choice` 消息块，不要把选项伪装成普通 Markdown 列表。
- `choice` 块必须使用以下标记包裹 JSON，且不要放在代码围栏中：

```text
<loomic_choice>{"type":"choice","questionId":"...","title":"...","options":[{"id":"...","label":"...","description":"..."}],"multiple":false}</loomic_choice>
```

## 家纺领域约束

先明确使用场景：床单/被套、窗帘、沙发或软包、壁布、桌布/靠垫，或其他家纺品类。记录成品方向、可视尺寸和印花工艺约束。

必须确认以下花型参数：

1. **回位方式**：四方连续（正方回位）、半落（half-drop）、镜像连续或条带连续。
2. **回位尺寸**：默认 64 × 64 cm；若用户有生产规格，使用用户尺寸，并记录 DPI、输出比例和安全边距。
3. **主题与元素层级**：主花/主图、辅花、叶片或枝蔓、点缀纹样；每个单元要有唯一名称。
4. **配色**：底色、主色、辅色、点缀色，优先控制在 3–6 个印花色；说明专色/数码印花倾向。
5. **密度与尺度**：主图占比、最小可印细节、花间距、留白比例、方向性，以及是否允许倒置。
6. **接缝安全**：元素不得在非目标边缘被意外裁切；边缘元素必须成对跨边或留出安全区，避免明显断线、重影和周期性硬边。

## 分阶段问答

### 阶段 1：花型 brief

依次询问品类与使用场景、回位方式、回位尺寸、风格主题、底色与配色、密度与尺度。确认后再创建单元。

### 阶段 2：分组花型单元

为主花、辅花、叶片/枝蔓和点缀纹样分别建立透明背景单元。用户提供参考图时保留风格、线稿、材质和色彩关系；不要擅自改变元素语义。每个单元记录层级、建议尺寸、旋转范围和可重复性。

### 阶段 3：组装连续花型

优先使用 `create_pattern` 创建回位，再用 `layout_pattern` 排布单元：

- `tossed`：自然散花，适合床品和窗帘满地花。
- `grid`：规则重复，适合几何或条理清晰的面料。
- 半落：相邻回位错开半个回位宽度，避免明显棋盘格。
- 主花先排，辅花与叶片用追加排布填充；使用稳定 seed 便于复现。

修改同一花型时沿用返回的 `patternId`，不要反复创建孤立预览。需要调整密度时优先修改 count、gapCm、scale 或 seed。

### 阶段 4：接缝与生产检查

调用 `check_pattern` 检查左右/上下接缝、边缘跨越、重叠、密度均匀度、空洞、周期性和最小细节。发现问题时先说明问题，再调整排布并重新检查。未通过检查前，不要宣称可生产。

### 阶段 5：预览与结论

给出至少一个平铺回位预览和一个家纺应用预览（床品、窗帘或软包任选其一），并用简短结论记录：回位类型与尺寸、底色和色数、主图尺度、密度、接缝检查结果、生产建议。

## 完成标准

只有在用户确认 brief、花型单元和拼接结果后，才执行最终生成或写入画布。最终回复应明确列出参数和检查结论；如果参数仍不完整，继续发出下一个 `choice`，不要猜测。
