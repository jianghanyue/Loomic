# 家纺连续花型设计与装配

这个 skill 适用于床品、窗帘、沙发/软包、壁布、桌布和靠垫的印花设计。它把“创意方向 → 单个透明元素 → 回位排布 → 检查 → 大图导出”保存为可复现的 pattern 文档。先阅读 [references/industry-research.md](references/industry-research.md) 了解本项目采用的行业和技术假设。

## 工作原则

- 如果用户没有给出完整 brief，先提出 3 组互相有明显差异的方向，每组写清主题、主花/辅花/叶片/点缀、底色、3–6 色印花色板、回位方式和建议尺度；等待用户选定方向后再生成图。
- 如果用户已经给了明确参考图和目标，直接整理 brief，只有缺少会改变产出的关键参数时才提问。不要为了形式强制逐题问答。
- 参考图用于保留风格、线稿、材质和色彩关系；不要复制可识别的品牌图案或把参考图整张直接平铺。
- 所有可复用元素都要有唯一 id、透明背景、物理宽度（cm）和层级。优先保留原始 PNG/SVG；AI 生成图只作为创意来源，生产前必须检查透明边缘和最小细节。
- 记录稳定 seed、回位尺寸、DPI、颜色和元素清单，方便同一方案的可控迭代。

## 元素构思与拆分

1. 先把选定方向拆成元素表：主花/主图（1–2 个）、辅花（2–4 个）、叶片或枝蔓（2–3 个）、点缀纹样（1–2 个），必要时单独加入边饰或条带。
2. 需要新元素时，用 `generate_image` 分别生成透明背景的单元；提示词中写明“单个元素、完整轮廓、无文字、无拼贴、透明背景”。一次生成一组概念时，仍要把最终采用的元素逐个落盘并命名。
3. 画布上已有一张合成图时，先用 `split_layers` 拆成 2–8 个对齐图层，再对需要使用的图层调用 `remove_background`；如果是纯色底，可指定 `mode=color`，复杂底图需要 ComfyUI 的模型抠图。
4. 对每个元素做透明边缘检查；不要把带白底、棋盘格或阴影背景的图片直接作为 motif。需要限制印花色数时可用 `vectorize_image` 做颜色归并，但要人工复核细线是否被吞掉。

## 回位与排布

1. 用 `create_pattern` 创建回位文档。常用回位尺寸为 64 × 64 cm；床品、窗帘或供应商有规格时以实际规格为准。`half_drop` 适合自然散花，`block` 适合规则几何，`brick` 适合砖式错位，`mirror` 适合对称或条带构图。
2. 先用 `layout_pattern` 排主花，再用 `append=true` 追加辅花、叶片和点缀。自然散花用 `tossed`，规则排列用 `grid`；用 `gapCm`、`scaleMin/scaleMax`、旋转范围和稳定 `seed` 控制密度、方向和重复感。
3. 主图不要全部等尺寸等角度；保留大、中、小三级尺度和约 20–40% 的留白变化。方向性花材只允许小范围旋转，非方向性碎花才使用 0–360°。
4. 元素跨越回位边缘时必须通过同一位置的 wrap-around 复制自然接回，不能只在预览中裁掉边缘。每次改动沿用同一个 `patternId`，不要创建孤立副本。

## 检查与导出

- 每次排布后调用 `check_pattern`。至少检查左右/上下接缝、跨边重叠、空洞、覆盖率和分布均匀度；报告有问题时先调整排布再重新检查。检查未通过不要称为“可生产”。
- 预览图只用于画布展示；生产文件调用 `export_pattern`，使用 `widthPx`/`heightPx` 或 `maxEdgePx` 指定输出。输出保持回位比例，任一边最大 16,384 px。`PNG` 保留 RGBA 透明度；`TIFF` 适合后续 ICC/CMYK 或印花厂流程。
- 16K 是拼接导出的像素上限，不代表生成模型原生能一次生成 16K。大图由透明元素在服务端以分块友好的方式重新采样和拼接，画布只保存轻量预览，完整文件写入项目资产。
- 按供应商要求记录有效分辨率与色彩配置。一般数码纺织印花以 150–300 ppi 作为起点，最终 ICC、专色、墨量和面料打样由印花厂确认。

## 输出给用户的方案说明

方案确认时列出：方向名、品类、回位类型和回位尺寸、底色与色数、元素 id/层级/建议尺寸、排布 seed、检查结果、导出像素与 DPI。至少展示一张 2×2 回位预览和一张元素拆分清单；如果用户还没确认方向，停在概念提案阶段，不要自动导出生产文件。
